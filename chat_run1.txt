## What’s going wrong with the needle

Flicker on **low E** is mostly the detector + lack of smoothing, not only mic noise.

Current `autoCorrelate` in `main.js`:

1. **Picks the global ACF peak** → guitar overtones often win → octave jumps (e.g. ~165 Hz instead of ~82 Hz).
2. **Buffer only 2048 samples** (~43 ms) → low E period ~12 ms → only ~3–4 periods → unstable lag.
3. **No Hz band limit** → noise peaks outside guitar range accepted.
4. **No smoothing / confidence / “hold last good”** → every frame moves the needle.
5. **`Math.floor` on cents** → extra ±1 cent jitter.
6. **`getUserMedia({ audio: true })`** → Android AGC / noise suppression often warbles pitch.

Commercial apps feel solid because they use a better estimator **plus** median + exponential smoothing + octave lock.

**Research pick:** implement **YIN** as the new default (strong on music, fewer octave errors). Keep your current ACF as **Classic**. Shared stability layer helps both. MPM (McLeod) is a later swap if needed.
